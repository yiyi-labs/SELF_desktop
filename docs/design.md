# SELF 沉浸体验与正确性审查

核对与实现：2026-09-21 至 2026-09-22。以新版 FINAL 提示词和用户追加的柔和氛围、音乐、多角度观察需求为准。

## 设计依据与实际平台

阅读了华为 [HarmonyOS 7 官方介绍](https://consumer.huawei.com/cn/harmonyos-7/) 和 [HarmonyOS 设计理念](https://developer.huawei.com/consumer/cn/design/concept/)。前者当前展示光随指动、光感粒子、光晕与空间层次；本项目据此选择安静、通透、连续的镜面构图，没有复制官方图片、视频、系统动画代码或宣称官方认证。

实际运行环境仍是 HarmonyOS API 19 模拟器。界面使用其可用的 ArkUI 圆角、透明度、阴影和 COMPONENT_REGULAR 材质模糊；背景使用本地 CSS，面容使用既有单一 Three.js 渲染器。它是兼容旧目标的设计适配，**不是已经接入 HarmonyOS 7 的全部系统光感接口**，更不是已经完成 HarmonyOS 7 真机视觉验收。

## 已实现的体验

| 部分 | 实现与边界 |
|---|---|
| 镜面空间 | 微光、暖阳、清透三组低饱和配色；渐变、慢速光晕、18 个边缘粒子和随拖动位置移动的背景光心 |
| 对话 | 一个原生玻璃回复区，保留上一次主动输入，简短回应柔和浮现；候选只有“试一下”和“保留现在”，没有美丑评分或缺陷列表 |
| 3D 观察 | 单指水平完整环绕、有限俯仰、双指缩放、回正；“轻转”启动小角度慢速摆动，手动操作/圈选/对照/详情/后台会停止 |
| 作品 | 保存模型姿态、相机距离与 PHOTO 平移；重开恢复观察角度；删除保存记录后当前临时资产仍可读取 |
| 音乐 | 原生 AVPlayer 播放三段本项目生成的 32 秒舒缓音轨，明确开关、默认关闭；切换先降低旧曲音量再释放，后台释放播放器 |
| 随话语调整 | 只匹配主动输入的少量明确表达，例如“我有点累”“我今天很开心”；可以关闭跟随或手选配色。不会因此自动打开音乐，不从脸、点击、停留时间推断心理 |
| 减少运动 | 应用内开关暂停背景动画并停止轻转；Web 监听 prefers-reduced-motion 的实时变化；静态时图形按需绘制，轻转时沿用一个 RAF 循环 |

音乐不是流媒体推荐系统，也不是心理诊断或治疗工具。不同配色/和弦由有限本地规则选择；未接入任意聊天理解模型。音轨由 `scripts/prepare-audio.mjs` 确定生成，没有抓取第三方录音；实际音频、采样率、峰值和哈希见 `assets/audio/manifest.json`。目前验证了原生解码、播放时间推进和生命周期，未完成听感用户研究、真机扬声器和音频焦点竞争测试。

当前示例为有明确 CC BY 3.0 来源的静态闭眼扫描。没有表情绑定、眨眼、眼球或呼吸形变；轻转是观察角度变化。照片仍保持 PHOTO 平面身份，不能三维转头。更鲜活的人像需要另行提供有授权且含完整表情资产的数据，不能通过伪造能力代替。

## 对宗旨与正确性的约束

1. 柔光与粒子始终位于透明 WebGL 画布后方；不进入脸部 shader，不加肤色曝光、bloom、美白、磨皮或结构形变。
2. 审查移除了整个画布的下缘淡出遮罩，避免在缩放或小窗口中淡化用户面容。屏幕脸部 alpha 保持原始路径；正式导出使用固定中性背景，UI 装饰不印入照片。
3. 导出和圈选冻结视角。圈选仍逐 UV 可见表面计算蒙版；没有将画线外框当作真实选区。手动旋转和选择工具互斥。
4. 改变与保留同等可达。音乐、动效、支持对话均可以拒绝；没有先贬低原貌的对比，也不把“不改变”变成必须接受的道德要求。
5. 聊天文字只保留在页面内存中；用户主动确认的私密记录才落盘。氛围分类不参与产品排序，不上传面容或聊天。
6. 当前仍是本地有限模板。对于未理解的表达不宣称深度理解，对产品只提供有来源的资料，不将通用数字颜色称为真实护肤功效。

## 实际验证

- 实际 API 19 模拟器：音频默认关闭、主动播放、切换曲目、后台暂停/前台恢复、动效关闭、轻转与圈选互斥、旋转角度保存与恢复。切换氛围前后正式 PNG 字节一致。见 [沉浸测试](evidence/immersive/results.json)。
- 桌面 Chrome：真实粒子运动、减少动画时停止已启动轻转、停止粒子后手动旋转仍有效；这些结果不替代鸿蒙系统无障碍设置测试。见 [设计专项](evidence/browser/design-results.json)。
- 核心原生编辑回归与完整未覆盖范围见 [验收清单](validation.md)。输入法首次弹出的独立协议未自动接受；真实键盘输入相关项仍单独记录状态。

仍需补充：真实人群体验、HarmonyOS 7 真机及系统光感材质、大字体/第二原生窗口、真正的人像表情资产、真实照片完整导入成功路径，以及 FINAL 清单中的专项保护例外等。上述范围没有用动画或漂亮截图替代验收。
