## 当前最重要的判断

低纹理不是“可以不重建”的区域。原有路径已经对有效room像素做RGB监督，不能再把问题概括成“以前只训练特征点”。仍然缺少的是足够可靠的连续表面表示，以及把表面深度、方向和前后遮挡真正接入优化。部分旧room大核仍能用跨深度混色拟合墙面颜色，同时污染人脸和衣物。直接移除它们又会丢失背景，这是表示与支持的问题，不是增加对比度、删背景或再加同样步数能解决的。

本轮新对照证实：保持全部头部参数不动，只改变room/body的受限模型参数，脸与头发误差也会下降。因此当前“脸上白雾”的一部分来自场景合成污染，不全是脸部纹理缺失。与此同时，PC与gsplat仍明显不同；不能把所有问题只归给任一端。

## 更可行的下一阶段路线

目标是让完整场景成为具有正确前后关系的表面集合，再保留标准3DGS表现细节。不能把所有内容改成平面，也不能把人像抠出来另贴背景。

### 优先动作：连续表面接替雾状体积

- 在原训练图中确定低纹理墙/柜门等连续域；使用已有相机条件深度、多视图一致性、边界和真实静态锚点共同约束深度与法线。白墙没有SIFT角点仍保留完整像素监督。
- 对确有平面证据的有限区域采用低自由度面片，对转角、突出物与不同深度物体分开。深度未知保留不确定性，不凭一个点延伸整面假墙，也不将当前候选池凸包当成永久边界。
- 在面片上分配切向覆盖和法向厚度，将旧宽核承担的**真实背景内容**交给一组方向正确、厚度有限的高斯。旧核错误遮脸的范围不属于必须保留的内容。先验证新表面在各观察中的颜色、结构和覆盖，再事务退役旧核。
- 用每条射线的可见表面次序及多视图一致性约束，而不是只比较高斯中心深度。当前新增包络约束可保留作诊断，不能伪装成完整表面重建。
- 对白墙等低频区域预算可以较低，对真实边界和褶皱增加容量；不能为了填空把单核放大成雾。密度新增须同步UID、来源、Adam与运动绑定。

### 人体连续性并行修复

- 衣物当前仅有短窗运动；跨时间头和上身不一致会让同一褶皱落在不同位置，外观优化会把它们平均软化。应以颈/肩/胸前分布式真实对应和轮廓约束上身与头部相对运动，再训练衣物，不能只靠更多SH颜色。
- 皮肤颈部用共享连续表面和受限运动过渡；衣领与皮肤是不同物理层，保持正确接触和遮挡，不焊成一张面或用透明度补缝。
- 面部保留现有可靠细节；头发保留独立体积和真实可见外表面，不能套用房间的强平面/薄层规则。镜框反光也不能当成实体厚度。
- 先局部和短窗验证，再完整场景一次共同合成；单个部件改善不能豁免合并后的退化测试。

### 成熟开源方法可借鉴什么

- [官方3DGS深度约束](https://github.com/graphdeco-inria/gaussian-splatting#depth-regularization)：对低纹理与漂浮点有针对性，但官方也明确部分场景可能变差。本轮借鉴其训练阶段几何约束思想，未复制实现。
- [DN-Splatter / AGS-Mesh](https://github.com/maturk/dn-splatter)：深度、法线和一致性过滤，适合借鉴室内表面约束；仓库Apache-2.0。不能直接用其旧依赖替换锁定环境，也不能将预测法线当测量真值。
- [PGSR](https://zju3dv.github.io/pgsr/)：借鉴射线与局部平面、多视图约束。其深度计算不是现有gsplat ED，不能通过加一个loss宣称已经复现；未复制代码或接入其光栅器。
- [2DGS](https://surfsplatting.github.io/)：表面表示与几何一致性有参考价值，但直接替换会改变光栅化/导出合同。本项目应先做局部表面约束并输出既有标准3DGS，所有导出仍双端实绘。
- [Mip-Splatting](https://niujinshuchong.github.io/mip-splatting/)：解决采样与尺度变化造成的伪影，不能用来替代错误几何或消除跨物体混色。当前classic/AA合同保持。

这些是可组合的几何与监督思路，不是把多个工程的训练器和参数默认值叠加。共同的K、尺度、W2C、参考时刻、SH方向与源点合同必须只有一套。

## 继续分析：本轮结果暴露的接口缺口与路线选择

以下是完成上述训练后的源码与公开方案复核；没有因此追加训练、修改生产链路或把候选改为通过。

### 已查实的运动监督不一致

`reconstruction_ray_surface.collect_observed_depth`对cloth与room使用相同的世界静态反投影/再投影：源深度由源C反投影后，直接交给目标C。它只限制cloth落在body_names短窗口，没有把点从源时刻的上身运动映回规范状态、再变到目标时刻。渲染侧却恢复了`motionMode=transition`及已有上身/头部过渡。因此“短窗近静态”只是近似，不是运动合同一致的证明。

这项实现缺口已经确认；它对本轮cloth退化的实际责任比例尚未通过单因素对照测量，不能把0115的全部退化归给它。尤其0115本身在五帧身体训练窗外，其身体姿态仍未知。本次cloth深度支持只能称静态假设下的一致性支持，不能称经过运动补偿的衣物几何。

后续刚体衣物观察应在统一尺度下使用：源相机点→源世界→规范上身→目标上身→目标相机。以C为W2C、B为规范上身到世界变换时，目标相机点为`C_b B_b inverse(B_a) inverse(C_a) x_a`。B必须来自通过检查的真实对应，不能直接把未经验证的光度运动当测量真值。颈部连续形变需使用实际局部形变映射；未知姿态继续保留RGB观察，但不得伪造它的跨时刻深度支持。

`transport_patch`目前传递的是每点旋转下的增量和尺度比例。零增量精确恢复已通过，但这不能证明颈部有限位移在非刚性变形下也正确。下一步需要将增量在规范空间施加后经过原形变，并核对`Sigma_t=J_t Sigma_0 J_t^T`，不可直接把刚体旋转测试作为颈部应变通过证据。

### 为什么继续叠加深度损失还不够

本轮所有点保持原拓扑、room位移仅在原位置附近有界。若起点本来是跨越不同物体/深度的宽核，有限优化可能只能在它们之间重新分配颜色与alpha，并不能产生缺失的墙、柜门和衣物接触几何。条件中心深度损失也看不到单个大核沿法向的全部厚度。因而本轮部分改善支持“几何与遮挡约束有价值”，不证明“继续同样损失训练更久就能彻底去雾”。

多张预测深度的一致也不等于独立真值；它们可能共享网络偏差。应保留真实轨迹、深度/法线预测、图像边界和可见性为不同证据来源。面部、头发、薄镜框与门缝处应降低不可靠先验的支配力，不能让低分辨率深度压平原片细节。

### 外部成熟方法的取舍

| 方案 | 对SELF有用的机制 | 当前接入边界 |
|---|---|---|
| DN-Splatter / AGS-Mesh | 深度—法线一致性，按先验可靠性调节约束，面向低纹理室内 | 采用局部监督与表面融合思路；预测先验不作真值，不升级旧环境。当前尚未实现完整法线融合 |
| PGSR / 2DGS | 表面方向、射线上的深度与多视图一致性 | 优先得到可追溯局部表面，再用标准3DGS表达；不直接替换两端光栅器，不把中心ED称射线表面深度 |
| MoSca | 从跨时刻轨迹建立受约束的运动骨架，将动态内容融合到规范状态 | 借鉴稀疏运动图；不整套移植其旧渲染器、深度网络与环境。当前SELF已有部件运动，先修交接再增加自由度 |
| StopThePop | 解释单深度排序在绕看时的混合与跳变，提供更准确排序的对照思路 | 用于区分病态宽核与排序误差；不将其CUDA实现直接当PlayCanvas可用接口，不以换排序替代几何修复 |
| Mip-Splatting | 采样与缩放变化的抗混叠 | 几何稳定后再单独评估，不能修复错误前后关系 |

[AGS-Mesh官方说明](https://xuqianren.github.io/ags_mesh_website/)明确指出深度/法线先验存在精度与多视图一致性问题，并按不确定性减弱约束。[MoSca官方仓库](https://github.com/JiahuiLei/MoSca)说明其当前实现仍有旧渲染后端，迁移到新版gsplat在待办中；主代码MIT不覆盖第三方模型/光栅器。它是有价值的研究参考，不是可直接保证8GB和现有合同兼容的现成替换。[StopThePop官方实现](https://github.com/r4dl/StopThePop)针对单深度近似造成的绕看混合伪影，需要训练/渲染配置相容；未接入SELF。

### 下一阶段的有限执行顺序

1. **先修衣物深度与运动合同。** 复用既有短窗和冻结模型，检查静止B、非零B、往返、遮挡、参考恒等与单位；以真实保留轨迹测量补偿是否改善。只让通过的观察参与衣物深度，不增加自由逐帧scale。该项不以背景分支完成为前提。
2. **主质量实验采用真实连续背景表面替换。** 在训练观测中按置信与连通表面选择区域，而非选某个历史帧的好看位置。先建立有限表面及误差区间，按切向覆盖、法向不确定性和图像边界采样。预先标记待替换核；只在隔离副本中验证新表面接管真实背景后，事务退役旧核。无法建立可信深度的区域保持未知及原有效内容，不能删掉或编造背景。
3. **同起点、同图像预算做控制。** 原表示有限恢复与新表面替换恢复分开；固定人物，完整共同合成。比较低纹理内容覆盖、门缝/转角、脸前room贡献、衣物/头发/脸的局部回归和连续绕看。原图中真实亮墙不应被当作“白雾”减暗。降低亮度偏差必须伴随结构/遮挡改善。
4. **身体与颈部扩大到有证据的连续窗口。** 已有五帧窗口不代表整个视频。先从颈、左右肩、胸前分布式观测约束运动，再以受限变形解释褶皱；不要求用户绝对静止。颈皮肤连续、衣领独立接触层，统一规范状态导出，不拼贴不同时间的头和上身。
5. **头发、镜框保留独立结构工作。** 头发需要真实外体积与遮挡，不跟随房间的薄平面规则；镜框以稳定线结构为依据。此次没有新增头发几何，不把头发RGB改善当作发型恢复。
6. **同一PLY继续双端实绘。** 在gsplat与PlayCanvas分别检查正常尺寸核、宽核的投影、排序、阈值及色彩，优先复用已有诊断。不能为让两端相同而放开半径限制、加曝光或把所有场景改雾。当前的双端差异尚未解决。

跨视频验证至少覆盖低纹理墙、复杂背景、轻微上身活动、有/无眼镜与不同发型；使用任务元数据、训练观察置信度和表面单位归一化决定行为，不按本人的帧号或物体颜色编码。现阶段仅当前视频跑过这项新stage，通用性仍是待验证目标。

8GB不是本次已证实的主要失败原因：两分支峰值Torch reserved约2.0/2.3GiB，无OOM。这不等于将来所有稠密网络都可同时装入8GB；应分阶段释放网络、缓存几何、逐视图全幅反传、局部事务恢复，并分别记录推理、准备、训练和显示耗时。不能用降低脸部像素精度来掩盖峰值问题。

不会承诺对任何单目视频恢复完全未被观测的真实内容。SELF应尽量使用全部有效可见影像，并明确观测不足的范围；低纹理本身不构成删除背景的理由。最终目标仍是内容完整、人物与场景自然连贯，而非只有更好的平均数值。
