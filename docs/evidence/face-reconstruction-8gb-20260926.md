# 个人面容重建与 8 GB 显存核验（2026-09-26）

> 历史阶段记录：下面的“仅头部训练、72 帧、两阶段任务”描述保留为当时实测，不代表当前生产管线。人物、衣物与背景统一重建及新增真实视频复测见 [连续场景记录](unified-person-room-reconstruction-20260926.md)。

范围：仅电脑端新任务的建模算法与环境。鸿蒙端既有查看器、编辑器、包名、签名、个人 PLY 和历史作品未改动。旧任务不追溯重训。

## 本轮改动

- 引入本机 CPU 运行的 MediaPipe 1.0.1 FaceLandmarker 与 SelfieMulticlass。模型字节、官方来源、SHA-256 见 `backend/models/README.md`。每帧用面部关键点圈出宽于轮廓的头部包络，再用皮肤和头发概率分割，膨胀边缘以保护耳、发和侧脸；相邻帧的大幅跳变被拒绝。无法稳定跟踪时任务失败，不回退到室内背景建模。
- COLMAP 4.2.0 只在头部掩码的白色区域提取特征，使移动的人头成为位姿恢复的主体。原始视频/帧不裁小，GS 训练继续使用原分辨率和原始 RGB；增加头部内像素损失、头部外透明度抑制、跨时序验证视角，以及导出前“至少一个真实头部视角支持”检查。
- 允许较少的稀疏头部种子进入增密，最终仍须通过留出视角的头部 PSNR、区域外透明度与导出数量门禁。数字质量指标保存在 `job.json`；视频、帧和临时掩码在成功或失败后清理。取消行为保持原样。
- 训练保持 float32、6000 步和原分辨率。每步结束释放渲染临时张量，只在 CUDA 未使用缓存超过 512 MiB 时清理缓存；显存分配峰值超过 7.4 GiB 时停止，不以降低分辨率换取通过。

## 本机实测通过

- RTX 5070 Laptop GPU 可用显存 8123 MiB；PyTorch 2.8.0+cu128、gsplat 1.5.3、pycolmap 4.2.0、MediaPipe 1.0.1。补装 Ubuntu `ninja-build` 与 `libgles2` 后，gsplat CUDA 前向/反向冒烟测试通过；新版 worker 重启后 `ready=true`，仅一个 worker 在运行，无活动重建任务。
- Google 的公开 `portrait.jpg` 单帧：识别 1 张脸，头部掩码占画面约 9.3%；目视包含面部、耳、发，排除绝大多数背景。18 张轻微平移的公开测试帧全部跟踪并生成掩码，用时约 15 秒。这是识别流程探针，不是侧脸视频。
- 合成纹理图的 COLMAP 遮罩探针：白色半幅保留 494 个 SIFT 点，黑色半幅 0 个。证明已安装的 `mask_path` 接口确实生效。
- 20 视角的合成 3D 场景：3000 步训练、留出视角检查与标准 Gaussian PLY 导出完成；头部 PSNR 57.58 dB、最差留出视角 56.85 dB、外部透明度 0、导出 7233 splats、峰值 CUDA 分配 20 MiB。**这些高分只属于简单合成场景，不能代表真实面容画质。**
- 1920×1080、35 万合成 splats 的单步前向/反向/Adam 压力探针：峰值 CUDA 分配 474 MiB，预留 514 MiB，低于 8123 MiB 可用总量。完整 6000 步真实捕获中的增密峰值仍需实测。
- WSL 面部/取消/原片清理测试 8 项通过；Windows 传输测试 8 项通过；脚本语法与 `git diff --check` 通过。当前已生成的合成 PLY 仍使用原 gsplat 导出器及 PlayCanvas 现有读取格式。

## 用户首条采集记录的真实视频（2026-09-26）

- 取自平板 SELF「采集记录」首条 `capture-1790305468164.mp4`，1920×1080、约 39.3 秒。HDC 接收副本与平板原片 SHA-256 同为 `f50b43c4e58defd15409c71826b0fa2fa228d305b7b0bb599fa7c93194454bc8`。先经电脑端相同的 1 MiB 分块接口完成一次重建（任务 `2b9dac18701d97af26d2e5909f4c3251`）；随后从平板应用首条记录点击「开始建模」，正式端到端任务 `9d6b5aff02dc470dcfc7b74fa70c1d22` 已上传同一 SHA-256、正在运行。两次输入一致，不能将前一次的电脑端结果冒充后一次的平板显示结果。
- 前一次任务跟踪 72/72 帧、注册 72/72 视角、面部区域稀疏点 6994、面部轨迹观测 45797；完整 6000 步训练的 8 个留出视角平均头部 PSNR 23.79 dB、最差 19.42 dB、头部外平均 alpha 0.0259。导出标准 GS PLY 201030 个 splats（约 47.4 MB），清除 4 个没有头部视角支持的 splats；峰值 CUDA 已分配 428 MiB、预留 610 MiB。电脑端资产字节数与 SHA-256 校验通过，原视频及临时帧按现有策略清理；平板原视频保留。
- 该视频估计视角范围约 -50.7° 至 +25.0°，左侧有效视角 19，右侧 0，`broadSideCoverage=false`。因此这次结果不能证明两侧面部同样清晰，更不能宣称全角度无背景遮挡；质量数字也不能代替目视验收。

## 尚未通过真实验证

- 平板首条记录的第二次任务仍需跑完、自动回传并在应用内显示；左右侧面均充分采集、头发边缘、眼镜/遮挡、动态表情、跟踪丢帧、面部与背景遮挡的目视验收仍不足。此次真实视频覆盖了部分照明与真实 6000 步显存峰值，不能外推到所有用户与环境。
- 面部掩码是 256×256 类别模型的估计结果并做宽边缘保护，不是像素级真值；COLMAP 的脸部特征可能在低纹理、模糊或过大转角时不足。此时应失败并反馈补拍，不能声称稳定精准建模或暗中发布背景模型。
- 数值 PSNR 与透明度不能单独证明身份细节、侧脸轮廓或无漂浮物；真实用户视频需以正面、左右侧面、俯仰及转动过程的视觉验收为准。
