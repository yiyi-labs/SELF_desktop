# 平板雀斑固定问答演示

只在 deviceInfo.deviceType 为 tablet 时启用。任意个人模型的圈选问答提交，都会使用同一段本地固定问题和回答；不要求云端权限、不上传画面、不绑定模型 ID。手机保持原有问答路径。

问题：这处雀斑让我无法见人了

回答：听起来，这处雀斑让你很在意，连见人都变得有压力了。雀斑也可以是很有辨识度的小特点。要不要先看看保留它的几种样子？喜欢哪一种，都由你决定。

沿用现有回答背景和圈选时确定的浮卡位置。输入框保持空白，不提供“试问”快捷入口；用户主动输入后发送。界面不显示演示标签或问题复述。提交后先显示正常 DeepSeek 等待提示，约 2.4 秒后使用同一 responseText / responseChanged / revealReply 模糊逐行浮现路径显示固定回答。文字最后一行清晰后，才显示图片及护理卡片。

会话框固定在圈选区域右侧，通常留 18 vp 空隙；右侧空间不足时收窄卡片，贴屏幕右缘，保持可读尺寸。按实际内容测量高度，用相同动画自动伸缩；可用空间由圈选位置和屏幕边界确定，不再固定限制到 320 vp。超出可用空间时滚动。等待期间清空、重画、换模型、隐藏会话或离开页面均使旧延迟回答失效。

回答下方展示自然保留、暖光气色、轻透玫瑰三个并排方案，均使用同一真实脸颊局部照片，仅做轻微光色调整并保留雀斑及纹理。图片署名、来源链接和许可已随页面及资源提供，详见 assets-src/freckle-demo/LICENSE.md。

“试在脸上”仅更新选中反馈并说明稍后开放，不向渲染器发送命令，不修改模型、编辑记录或保存数据。护理卡提供 OLAY 小白伞防晒和可选淡斑小白瓶的资料入口，可收起；不承诺消除雀斑，不把图片与产品功效关联。

验证：固定问答、延迟取消与圈选布局 9 项检查通过；HarmonyOS 调试包构建成功。此前已在连接的真实平板验证本地固定回应可触发及原有浮卡背景、位置；局部照片已逐张检查。视觉示意图位于 artifacts/freckle-demo/skin-options.png。
