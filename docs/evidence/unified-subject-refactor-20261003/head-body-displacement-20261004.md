# 头身分离根因与修复（2026-10-04，承接统一主体重构）

## 证据链（作业 bdc65c2e，用户真机截图对应资产）

1. 资产解剖：65291 点 = room 30887 / skin 11685 / hair 8000 / body 14719。
   **皮肤云与身体云最近距离 29.1 世界单位（view 距离 10.4）**；对照作业
   （7f92a537、run-scene2）同指标 1.56 / 1.83 → 非系统性导出缺陷。
2. 导出链逐项反验无罪：PLY 头云经 to_world(C_ref,F_ref,scale) 逆变换回头局部
   紧凑（0.217×0.355×0.197）；各帧头世界原点彼此靠近；checkpoint 环境=PLY 环境。
3. 身体组件（DA3 part4）点到**其源相机**距离中位 49.6–53.0（应为 10–20）
   → 深度尺度膨胀 ~3.5×。房间窗口同管线锚定正确（训练期房间空洞 0.028）。
4. 机制：infer_request 中 DA3 深度为带尺度输出，唯一度量锚=DA3 自估外参与
   已知相机的对齐（align_camera_scale）。人物特写窗口缺静态背景 → 外参退化
   → 尺度错 3.5×；0.25 RMS 门度量的是对齐拟合质量而非深度真值，未拦截。
   训练中环境 means 学习率 600 步最多移动 ~1.4 单位，永远追不上 29 单位错位
   → 最终资产=清晰的漂浮头 + 远处错位身体（即真机截图）。
5. 次级确认：背景方位×俯仰占用网格 50/72 格为空（背景覆盖不足为独立问题，
   见待办）；头发各向异性中位 5.0、>20 占比 1%（"扇片感"源于外观/密度，
   非病态几何）。

## 修复（提交 4c9a497，闭包重钉 87706ba8…）

- `live_dense.flame_depth_anchor`：body-world / head-local 窗口深度尺度改由
  逐帧 FLAME 拟合（度量级、landmark 验证）在人脸/颈像素上锚定；
  样本<120 或离散(MAD/中位)≥0.35 或因子越界 [0.05,20] → 拒用该窗口。
- 回放验证（run-scene2 留存 DA3 深度，正确尺度窗口）：body 因子 1.034
  （13457 样本，离散 0.054）；head-local 因子 1.04–1.08（3–3.4 万样本，
  离散 0.03–0.05）——正确窗口不被破坏，头发窗口外参残差同步收紧。
- `export_candidate` 结构门：中位皮肤→身体距离 > max(0.6×身体半径, 2.0)
  → `portrait_body_displacement_detected` 拒绝发布（历史案例 29 vs 阈值≈13）。
