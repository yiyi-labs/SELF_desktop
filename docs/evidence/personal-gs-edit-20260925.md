# 个人 3DGS 圈选与 DeepSeek 编辑验证（2026-09-25）

后续多区域/历史记录改动与测试见 [multi-region-olay-research-20260925.md](multi-region-olay-research-20260925.md)；下文记录的是首版单区域验证状态，不代表当前操作上限。

## 本轮边界

仅为已建好的个人 3DGS 模型增加编辑入口。原始 PLY 保持不变；拍摄、重建、星辰导航、签名和既有作品没有迁移。PlayCanvas 锁定 2.22.4，圈选在个人 GS 查看器内部执行，不把原生界面的色块覆盖在模型上。

## 实际链路

1. 平板加载个人 PLY（此次测试模型为 107,948 个 Gaussian），切换到「圈选」，手指在面容上圈出范围。查看器按当前视角投影 Gaussian 中心，用深度前层和边缘羽化计算逐点遮罩。遮罩绑定原有 Gaussian ID；旋转相机后仍跟随这些点。
2. 用户输入愿望后，应用征求本次静态画面发送授权。只向已配置的本地后端发送原始视角图、圈选标注图与文字；不发送 PLY。后端调用真实 DeepSeek 工具规划，返回候选，不直接改变模型。
3. 用户确认候选后，查看器按遮罩修改选中 Gaussian 的 DC 颜色系数，保留 SH、透明度及未选中的点；调用 PlayCanvas 的颜色纹理更新和一次工作缓冲更新。操作名为「数字试色」，不能作为产品真实效果。新版本调高了原先难以察觉的颜色混合比例，并提供「看原样／看变化」本地对比；尚需在真机上复测实际可见度。
4. 应用在该模型私有目录保存遮罩与编辑配方（资产大小、点数、遮罩校验值、颜色和强度）。再次进入时校验后恢复；「恢复原样」本地执行并删除配方，不需调用模型。一次只保留一处数字编辑，新选区会提示替换。
