# 多区域 GS 编辑与中国区 OLAY 资料边界（2026-09-25）

## 已实现

- 保留原始个人 PLY、PlayCanvas 2.22.4 查看器及现有星辰界面。一次可连续手工圈选四处可见的 3D Gaussian 点；每处有独立 ID、遮罩和标注序号。向 DeepSeek 发两张经本次许可的静态视角图，返回至多四个受约束的候选操作；用户确认后整组提交。
- 查看器从原始 Gaussian DC 颜色重放已保存的数字试色层，不跨原生/网页表面悬浮色块。`portrait.edit.v2.json` 按模型私有目录保存组、单项、蒙版校验、强度和名称；旧 `portrait.edit.json`/`.mask` 保留并可读取，原始 PLY 不修改。支持整组或单项对比、删除，最后一组本地撤销。
- DeepSeek 对痘印、疤痕等部位不主动下缺陷判断；当前没有可靠的结构/肤质编辑能力时解释或澄清，不把红色数字试色伪装成遮瑕或护理效果。回复在对话旁以 `✧` 标明为模型建议。
- 采集引导增加左右各一个 60° 可选观察格；仅在商业 Core Vision Kit 给出新鲜、高置信观察姿态时点亮。原有正面及中侧面质量门槛没有降低，无法检测到侧脸时不会制造已采集状态。
- 从用户提供的 `SELF_OLAY_CN_审计修订版_20260925_v2.zip` 导入 74 条研究记录及来源复核状态到 `shared/products/audit-v2/`。文件哈希记在 `provenance.json`。这不是 74 个当前在售、已核配方的单品；其中 17 条为 2026 品牌资料观察，46 条目录线索，10 条历史，1 条品牌搜索线索。标定 profile 和批准发布清单均为 0，暂不让这些记录驱动真实产品效果。

## 产品效果的下一道门槛

单品至少要绑定中国大陆实物的名称、变体、规格、批次/版本、适用部位与使用条件；再用受控前后影像和多角度 3D 资料标定即时光泽、颜色、反光、纹理及不同时点变化，并在未参与标定的人/视角上验证。洁面和身体护理不能套用留置面部效果；套装不能当单一配方；长期护理宣称不能用一段预设动画冒充。现有 3DGS 的 DC 数字试色只验证了颜色层，不支持经验证的产品反光、肤质、遮挡或长期功效。

公开核对入口：[OLAY 中国官网](https://www.olay.com.cn/)（当前可读页面是 JS 壳，不能据此核全 SKU）、[OLAY 京东自营旗舰店商品目录](https://olay.jd.com/view_search-404604-0-5-1-24-1.html)（渠道展示，不是配方/标定）、[华为 Core Vision Kit](https://developer.huawei.com/consumer/cn/sdk/core-vision-kit)（人脸框、特征点、朝向能力概述）。研究数据文件没有复制官网产品图；演示图形继续使用 SELF 自有资产。
