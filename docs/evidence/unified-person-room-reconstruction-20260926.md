# 人像与环境连续重建：历史采集离线复测（2026-09-26）

本记录使用 SELF「采集记录」首条历史视频的电脑端副本。原片 SHA-256 为 `f50b43c4e58defd15409c71826b0fa2fa228d305b7b0bb599fa7c93194454bc8`，时长约 39.3 秒，约 1181 帧。没有要求用户重新拍摄。平板在本轮离线测试时已断开；本记录的数值和图片**不能视为新的鸿蒙端显示验收**。

## 问题和改动

- 旧流程固定只取 72 帧，又把面部和环境分别恢复为两套相机轨迹并合成。两个轨迹存在可测的偏移；身体皮肤与衣领附近的过宽排除区也容易留下洞。抽帧并非原视频中断，原视频解码连续。
- 新流程在原始空间分辨率上完整解码，按短时间窗选较清晰的帧。本段取到 158 帧，原片没有被缩小。面部跟踪通过 158/158；抽样帧的面部锐度中位数从约 152 提升到约 166（同一探针量纲）。
- 人物、衣物、房间全部参与**同一次 COLMAP 相机恢复和同一次 gsplat 训练**，只是面部像素在损失中有更高权重。环境深度种子来自相同相机、已三角化的真实视频观测；不独立训练背景模型，也不在导出时把两份 PLY 拼接。面部范围的标记仅用来保留既有圈选编辑入口。
- 缩小头部附近的环境排除边界，并允许颈部、衣服和环境共同训练。场景半分辨率与面部原分辨率裁块交替训练，每 50 步加入原分辨率整帧；这降低峰值显存，但没有缩小最终资产的原始采集分辨率。
- 查看器根据真实相机覆盖限制侧向视角，并在横屏时按原相机水平视角调整开场构图。限制只影响观看范围，**不从模型中抠除背景**。

## 本机真实视频探针

- 单一场景恢复 158 个注册视角、约 2.57 万个稀疏点；约 1.32 万个面部与约 1.33 万个环境点得到观测，另有约 815 个跨人物边界的过渡点。环境增补约 4.03 万个深度种子，仍在同一坐标系。
- 独立的生产训练器复测完成 3000 步，导出约 13.75 万个高斯点，其中可编辑面部约 5.32 万、衣物/环境约 8.43 万。留出原片视角：面部约 27.5 dB、环境约 26.55 dB、环境平均不透明度 0.9988；CUDA 峰值分配约 374 MiB。这些是训练探针的图像指标，不足以单独证明任意侧面都无孔洞。
- 源相机四个时刻的离线渲染中，面部 PSNR 约 22.89–31.14 dB、环境约 25.94–30.32 dB，人物与环境接缝附近 alpha 约 0.991–0.999。目视确认已拍到的正面及一侧视角中脸、颈、衣服和房间相连。
- 以平板横屏比例进行离线自由转动探针，约 -40° 至 +15° 的画面连续性较好；+30° 开始出现边缘缺口，+45° 不能接受。原片相机覆盖约 -54° 至 +25°，没有拍到对称的另一侧。生产查看范围据此收窄，不能把不存在的视角当作已采集。

## 完整生产流程复测

- 使用同一原视频副本从 `reconstruction_worker.run_one` 开始，依次通过文件字节与 SHA-256 核验、158 帧选择、158 帧面容跟踪、158 帧统一相机注册、环境深度播种、3000 步人物与房间共同训练、PLY 与缩略资产导出。最终任务状态为 `gaussian_ready`。
- 最终模型 133416 个高斯点，面部可编辑范围 51587，环境与衣物 81829；留出视角面部 27.66 dB、房间 26.65 dB、环境平均 alpha 0.992，CUDA 峰值分配 368 MiB。最终主 PLY 为 31487653 字节，SHA-256 `73f6e513443a6f84e373db675c64f416f8630888040895afc2d76da778a09e69`。主 PLY、视角配置、PNG 预览及两份星辰 LOD 的字节数与 SHA-256 均通过独立复核。
- 生产流程结束后，其任务目录内原视频、抽出的帧、分割掩码与 COLMAP 临时文件均已删除。保留的五项成果及任务清单位于 `artifacts/reconstruction/first-capture-unified-20260926`；其他离线探针的视频副本和帧也已清理。平板原片及既有作品未触碰。
- 最终 PLY 在电脑 GPU 离线渲染的正面、约 -40° 和 +15° 画面中，面部、颈部、衣服与可见房间连续，面部未被大块背景遮住。横屏相机向下微调视线后，完整下巴与部分衣领进入画面。画面最外侧仍有稀疏、拉丝和暗区，故**未通过“任意侧向视角、整幅背景绝对无孔洞”验收**。这些是本机渲染观察，不是平板截图。
- PlayCanvas 查看器资源已重新打包，DevEco 商业 SDK 的调试签名 HAP 构建成功；未连接平板，故未安装或做真机帧率、显示与圈选复测。

## 边界

算法可以利用连续视频中此前丢掉的清晰帧，统一人物和背景的几何与颜色；它不能从未拍到的背面恢复真实细节。现有片段只能检验其实际覆盖的方向。需要双侧较大角度自由观看时，后续采集必须有相应真实视频；本轮没有对用户提出重拍要求。

平板断开期间，只完成电脑端离线探针和既有 PlayCanvas 资源构建。新的 PLY 在当前 API 26 平板上的加载、转动、缩放、圈选、编辑和回传仍待连接后实测。禁止把这里的 GPU 渲染截图写成平板截图。
