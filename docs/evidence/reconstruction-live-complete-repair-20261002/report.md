## 本轮实际算法修改

1. **完整影像支持的表面初始化。** 固定 DA3 BASE 代码 `3d835ec1a5802d64a8b8b15f817a1ab54809bfe4`、模型 `f4a6c9b3c95e41c82048423d3493a81ec3fa810e`，权重 SHA `e01067dc1659613083d9145a9a2547ccdbe6ccbbf83c4fe7b3e8a4e2bdae78b5`。代码与 BASE 权重按锁定许可记录使用，不改原 CUDA/PyTorch。其深度是相机条件下的提议，不能冒充测量真值。保留原 K/F/C、全幅像素、单位、SH 和 PLY 合同。
2. **表面协方差真实交接。** 环境和衣物保留切向、法向各向异性，不再用稀疏种子间距生成巨大圆团。头发从有多视图支持的局部表面初始化，替换旧壳；原面部前缀保持完整。头发局部位移有界并实际训练，未因此宣称发型已精确。
3. **弱纹理背景不以低置信度直接删除。** room 的预测置信度用于权重，不能直接抹去最低一档像素；原深度一致性和可靠空区检查仍保留。针对多视图深度系统偏差，增加一个共享世界表面的有限逆深度校正，不逐视图自由扭曲。固定 K/C，用独立轨迹留出核对深度和重投影。
4. **背景条件证据显式区分。** 严格深度支持与共享表面条件支持保存在不同字段。静态 mask、原色一致不是独立可见性/深度真值。缺少足够几何证据时保留原初始化并记录未应用原因，不伪造通过。
5. **替换范围外全部保留。** 修正过程中发现旧预算会再次抽样范围外背景。已改为先保留全部范围外旧点，剩余预算只分配新表面。最终受控候选恢复 1,632 个被预算误排除的旧点；15,770 个范围外旧点全部参数逐位不变，加 14,230 个新表面点，总数仍 30,000。
6. **衣物与颈部。** 使用真实参考时刻附近的短观察窗口，补足连续邻帧；头与上身不强制共同旋转。颈皮肤以连续运动场连接，协方差通过其 Jacobian、SH 通过局部旋转运输。衣物/room 分开 Adam 时钟，避免零梯度仍有旧动量漂移。所有组件仍共同前向遮挡，未删除人物后方环境。
7. **颈部亮带。** 精确贡献分析确认一部分是上方头模颈部颜色与下方真实皮肤颜色不一致。仅选择在多个训练观察中贡献于颈部、对脸/头发/眼镜无可见贡献的 330 点更新 SH；其余头部参数逐位不变。没有把颜色接近等同于几何接缝完全解决。
8. **头发发白。** 一些侧面亮背景透过半透明头发。新旧完整画面中的头发贡献相同，说明不能以删背景修复。增加完整场景下的有限头发颜色/alpha 恢复，所有几何及非头发参数固定；这不是新增头发几何或刷黑发壳。
