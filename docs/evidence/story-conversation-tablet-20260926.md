# 建模后会话与界面验证（2026-09-26）

范围：保留个人 3DGS 查看器、原有圈选和数字预览编辑；只核对建模后文字会话、视角只读回传接线及相关界面。

## 本轮实际通过

- 商业 SDK 26.0.0.821 下完成 debug HAP 编译与签名，覆盖安装到已连接的鸿蒙平板；应用正常启动并打开已有个人 3DGS 作品。
- 平板横屏布局检查：顶部“我的星辰／回到原点”在同一 46 vp 高的容器中，两个入口有独立且对齐的点击区域。分别点击后，确实进入星辰空间与原点。
- 底部仅有一个深色会话输入区域，没有外层蒙版或第二层输入底板。提示逐字模糊浮现在输入框内部，获得焦点或输入后消失。系统键盘弹出后，输入框保持在键盘上方；输入和发送按钮均可触达。键盘收起后输入框回到屏幕下方。
- 用显式的合成测试文字在平板发送一次请求。首次出现“只发文字”确认；确认后经 HDC USB 反向端口进入本机服务，并收到了 DeepSeek 的简短回复。该次测试没有保存为用户作品或观察记录，也没有发送面容画面。
- 回复显示在同一底部会话区域的上方延展部分，短回复按内容收缩，长回复可以滚动。切换到圈选时会话输入区域消失；切回移动时重新出现，且没有独立的第二个 SELF 对话框。
- 后端文字契约相关 31 项单元测试通过；GS 选区与撤销等 7 项测试通过。

## 边界与待验证

- 已构建只读 GS 视角回传和“原话＋视角”的私有记录路径，但未在用户作品上保存测试原话，故平板端的保存／删除全过程尚未做实证。
- 本轮没有重测真实 OLAY 实物效果、面部侧面所有角度的上脸效果或新重建。现有数字预览不等于产品实测或时间预测。
- 当前平板的系统输入法仍使用自身的亮色分栏键盘。应用请求了暗色沉浸外观并负责避让，但普通应用无法保证系统输入法外观或强制默认悬浮布局。
- 文字服务当前由本机 8788 端口提供，并通过本次 USB 会话的 HDC reverse 暴露给设备的 8787 端口。电脑服务或 USB 会话中断时，云端对话无法继续；本地 3D 查看及原有撤销不依赖它。
