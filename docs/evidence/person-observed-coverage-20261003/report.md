## 已定位的实现缺口

1. 房间窗口因共享图的条件深度差而整窗拒绝，后续矫正也仅看acceptedWindows，导致有可靠C和独立静态轨迹的早段/尾段观察无法进入矫正。T3仍监督这些图的room RGB，但缺少相应表面。修复应固定相机先校正、再做局部跨表面一致性验证，不放宽原拒绝阈值。
2. T3原衣物覆盖项使用场景total alpha，后方room可以补满指标。新增同次排序/透明合成person_rgb与q_skin+q_body，背景不能代替人体满足覆盖。
3. 旧局部预乘RGB与弱覆盖项允许颜色和alpha补偿。新增可靠不透明内部的条件颜色及透射约束，头发、镜片、未知与物理层边界不强制不透明。
4. 原人脸按完整模板面积生成统一初始footprint，过滤后实际邻距与footprint不匹配；不能仅从总点数判断细节容量。相容表面采样间距初始化为独立因素，需同预算真实训练验证。
5. 当前F是准备阶段的关键点拟合；局部900步确实改变共享表面，却没有真实纹理约束下的后续F校正。新增不透明约束不能冒称解决所有几何错位。
