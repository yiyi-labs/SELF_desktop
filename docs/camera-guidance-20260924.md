# 拍摄跟随与视角引导复核（2026-09-24）

参考画面：用户提供的 Remy 演示截图，仅用于底部球形视角引导的交互参考；没有复制其图像或资产。

## 处理方式

- 首次小圈锁定要求同一张脸的五点结构有效、连续三帧稳定；多张脸或大幅跳变不能直接接管锁定。
- 锁定后对鼻尖坐标使用速度自适应低通，并限制单帧最大位移；短暂识别丢帧保留上次位置，超过约 650 毫秒则重新寻找。滤波思路参考 [1€ Filter 原论文](https://direction.bordeaux.inria.fr/~roussel/publications/2012-CHI-one-euro-filter.pdf)，参数是工程初值，仍需真人走动复测后校准。
- 相机方向由 Camera Kit 的 `getPreviewRotation`、实际镜头安装角度与屏幕旋转角度记录。ImageReceiver 分析输出固定在原始方向，分析图像再按对应预览方向旋转；圈与粒子通过统一的镜像、等比填充和居中裁切公式映射到预览。前置镜头默认按镜像预览处理，说明面板提供对齐切换，避免不同设备预览策略造成不可纠正的偏移。华为[相机旋转与镜像说明](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/camera-rotation-term-native)是此处的依据。不同输出 Surface 的镜像一致性仍需本机画面核对。
- 底部球形卡片以 Core Vision Kit 返回的相对人脸偏航角点亮五个视角扇区。只有在真正录像、识别置信度达标、面容完整、姿态不过分倾斜，且新的官方姿态样本在同一区间持续至少 250 毫秒时才点亮。缓存样本不重复计数。左右方向按前置预览镜像变换。
- 该角度是**相对面容视角参考**，无法单独证明相机平移、足够视差、清晰度或 3DGS 重建质量；因此计满五区也不自动宣称建模完成。

- 本机 DevEco 商业 SDK：签名 HAP 构建通过；HDC 覆盖安装到 MatePad Edge QXS-W10 成功，保留原应用数据。新加 `SELF_CAMERA_ANALYSIS_STREAM` 只记录帧尺寸、格式和方向，不记录图像像素。
- 最初安装后平板锁屏阻止启动；解锁后于 09-24 08:44 和 08:47 通过 HDC 覆盖安装、启动并进入拍摄页。用户自行确认竖屏方向通过。当前版本真机日志显示 540×960 NV21 分析流、两套检测器正常启动、面容结果出现和小圈进入跟随状态；没有采集新的录像或保存人像。真人运动时小圈贴合误差和 11 档指针的视觉质感仍需用户验收，不能仅凭日志判定通过。

## 9 月 24 日后续修订：抑制鼻尖漂移与细分视角

- 用户已在真机自行确认竖屏方向通过；对鼻尖仍有小范围漂移的反馈促成了这次修订。锁定后，当鼻尖单独跳动、双眼中心几乎不动且没有独立的官方姿态转动证据时，跟随双眼的位移而不直接追逐鼻尖跳点。只有本地检测器的五点继续驱动小圈；官方检测器不再在某一帧临时接管坐标。两套检测仍共同确认目标、官方偏航角仍用于视角引导。
- 视角由五档改为相对人脸偏航角 `-50°..50°`、每 `10°` 一档，共 11 档。球形引导上新增移动指针；点亮需要录像中、面容完整、官方姿态新样本在该档中心 `±5°` 内持续至少 250 毫秒。档位切换有约 2° 滞回，防止边界来回闪烁。
- 粒子由固定二维椭圆改为随着偏航角投影的**规范曲面示意**，点更小且半透明；额外标出当前算法真实返回的双眼、鼻尖、两侧嘴角五点。这改善视觉上的侧面包裹感，但**不是对个人面部真实三维曲面的贴合**。不能将这些粒子当作 3D 重建数据，也不能把 11 个点亮档位当作视差或清晰度证明。
- 对照已安装的商业 SDK API26，Core Vision Kit 检测器只有五个 2D 特征点和姿态。AR Engine 从 6.1.0(23) 起定义了 `ARFace.getGeometry()` 和 84 个 2D/3D 面部关键点；但只支持部分平板，且需要专门 AR 会话/相机链路。MatePad Edge 真机调用 `HMS_AREngine_CheckSupported(ARENGINE_FEATURE_TYPE_FACE)` 返回 **801（设备不支持）**，因此本设备不能以 AR Engine 实现真实三维面部贴合。华为官方参考：[AR Engine](https://developer.huawei.com/consumer/cn/hms/huawei-arengine)、[AR 会话与设备约束](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/arengine-c-arsession)。
- 本地 `libfacedetection` 推理图像长边从 400 提升到 480 像素以保留更多鼻、眼局部信息；在这台真机上日志的推理耗时由约 40–56 ms 增至约 50–91 ms，总分析周期多在 180–230 ms。没有客观鼻尖误差标注，**不能据此宣称识别精度已提高**；后续要以真实运动序列、关键点真值或人工标注对照决定是否保留该分辨率。
- `npm run test:camera-guidance` 增加鼻尖单点跳变、整脸平移、11 档新样本/边界/镜像、粒子低透明度测试。真人移动时的稳定性、侧脸贴合仍需真机主观和量化复测。
