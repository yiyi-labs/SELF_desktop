# 拍摄跟随与视角引导复核（2026-09-24）

参考画面：用户提供的 Remy 演示截图，仅用于底部球形视角引导的交互参考；没有复制其图像或资产。

## 处理方式

- 首次小圈锁定要求同一张脸的五点结构有效、连续三帧稳定；多张脸或大幅跳变不能直接接管锁定。
- 锁定后对鼻尖坐标使用速度自适应低通，并限制单帧最大位移；短暂识别丢帧保留上次位置，超过约 650 毫秒则重新寻找。滤波思路参考 [1€ Filter 原论文](https://direction.bordeaux.inria.fr/~roussel/publications/2012-CHI-one-euro-filter.pdf)，参数是工程初值，仍需真人走动复测后校准。
- 相机方向由 Camera Kit 的 `getPreviewRotation`、实际镜头安装角度与屏幕旋转角度记录。ImageReceiver 分析输出固定在原始方向，分析图像再按对应预览方向旋转；圈与粒子通过统一的镜像、等比填充和居中裁切公式映射到预览。前置镜头默认按镜像预览处理，说明面板提供对齐切换，避免不同设备预览策略造成不可纠正的偏移。华为[相机旋转与镜像说明](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/camera-rotation-term-native)是此处的依据。不同输出 Surface 的镜像一致性仍需本机画面核对。
- 底部球形卡片以 Core Vision Kit 返回的相对人脸偏航角点亮五个视角扇区。只有在真正录像、识别置信度达标、面容完整、姿态不过分倾斜，且新的官方姿态样本在同一区间持续至少 250 毫秒时才点亮。缓存样本不重复计数。左右方向按前置预览镜像变换。
- 该角度是**相对面容视角参考**，无法单独证明相机平移、足够视差、清晰度或 3DGS 重建质量；因此计满五区也不自动宣称建模完成。

- `node scripts/test-camera-guidance.mjs`：首次锁定、丢帧保留、跳变拒绝、视角去重、前置镜像及横竖屏中心裁切测试通过。
- 本机 DevEco 商业 SDK：签名 HAP 构建通过；HDC 覆盖安装到 MatePad Edge QXS-W10 成功，保留原应用数据。新加 `SELF_CAMERA_ANALYSIS_STREAM` 只记录帧尺寸、格式和方向，不记录图像像素。
- 安装后平板处于锁屏，系统拒绝从电脑启动应用，故**新界面的实际显示、横竖屏圈位置、真人移动稳定性未完成真机验收**。旧版曾在真机完成相机及录像测试，不代表本版的视觉贴合已经通过。
- 用户既有拍摄内容不在本轮测试中读取、上传或删除。Windows 重建工作器和个人 3D 回显仍未接通。
