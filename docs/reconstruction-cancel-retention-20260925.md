# 重建取消、过渡与电脑端视频清理核验（2026-09-25）

这次核对发现旧工作器在任务成功或失败后仍保留 `capture.mp4`、抽帧和 COLMAP 临时数据。现在成功任务先确认 Gaussian、视角文件和可选预览资产，再清理电脑端视频及中间文件，只保留 `job.json` 与已发布资产；失败任务只保留任务状态。鸿蒙应用私有 `filesDir/captures/` 中的原片不受电脑清理影响，仍由用户在采集记录里决定是否删除。资产保留在电脑端，允许平板网络中断后重取。

取消按钮在尚未创建任务时阻止继续上传；已创建任务会调用 `POST /v1/reconstruction/jobs/{id}/cancel`。接收中的分块立即清理；同一任务的分块写入、合并、取消和删除串行处理，防止在取消后被较早开始的请求重新写出视频或旧状态。排队或运行中的任务由 WSL 工作器停止训练子进程后清理，避免删除正在被使用的文件。应用确认 `cancelled` 后回到主页，不替换原有作品。`cancel_requested` 是清理过程中的中间状态。

经用户确认，历史 3 个 `gaussian_ready` 和 1 个 `failed` 任务已清理电脑端视频与临时文件。清理前逐项核对 3 个完成任务清单中的资产大小与 SHA-256，均通过；清理后再次扫描，待清理条目为 0。未改动已发布 Gaussian、视角文件、任务记录、平板原片或已保存作品。迁移脚本 `backend/purge_completed_inputs.py` 默认只审计，只有 `--apply` 才执行清理，并拒绝越界路径或资产校验失败的完成任务。

过渡画面改用程序绘制的星空，不播放视频。等待时只保留较小的光圈，落点设在画面中线附近。光圈高度由逐帧积分的重力与碰撞速度决定，落点后的轻微环境脉冲只调整下一次起跳速度，使连续弹跳的高度小幅变化；环线随撞击力度短暂压缩、回弹。首次落点从中心扩散粒子；后续落点让近处星粒先沿短暂弹道上扬、再向外传递不规则波动，强度按时间衰减，不绘制固定圆线。固定的地面椭圆阴影与毛玻璃容器已取消。左上角文字逐字浮现，星辰命名与细进度线位于下方。首页星空固定粒子采样步长，并在场景数据加载后渐显，降低突然变亮的可能。视觉处理参考华为[HarmonyOS 设计概览](https://developer.huawei.com/consumer/cn/design)与[动效使用指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-animation-usage-guide)所述空间感、光学层次和符合物理预期的运动；这是 SELF 自绘画面，不声称复制华为系统的图形资产。

一次真机复测在 USB 端口映射消失、工作器健康心跳过期时未进入等待画面，应用显示可重试状态。检查发现取消任务的旧工作器曾在跨 Windows/WSL 删除抽帧目录时收到短暂的“目录非空”，同时客户端已把状态当作完成清理，进而发生竞态。现在工作器先完成带重试的清理、最后发布 `cancelled`，异常时保持工作器存活供下次重试；API 不允许删除 `cancel_requested` 任务。服务与 USB 映射恢复后，同一真机取消探针再次通过，随后健康接口仍返回 `engine:ready`。此失败和修复不能推出未来 USB 连接永不中断。

本轮未重新跑一段**真实成功**的人像 GPU 训练，也没有做逐帧动画流畅度测量。因此成功后的自动清理由单元测试和代码路径验证，不能当作新一次“真人人像建模成功”的实测。真机测试只证明取消链路与已有模型未受损；个人模型面部细节与可编辑贴脸圈选仍需单独验收。

真机回归再次通过首页、设置、拍摄入口和历史星辰导航。历史星辰预览文件仍在私有目录，但这次日志中未出现 `SELF_STAR_3D_READY`，不能以导航通过推断预览渲染已重新验证。先前一次取消于 10:42:43 完成，之后出现的是另一个独立新任务，不是原任务恢复上传；该新任务也已取消并删除。最后一版弹跳的连续性目前由代码审查、数值轨迹和真机静帧核对，是否符合主观观感仍以用户亲自观看为准。
